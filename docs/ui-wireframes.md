# UI Flows and Wireframes

## Student mobile

### Home
- New Complaint
- My Complaints
- Notifications
- Profile

### New Complaint
Title → Description → Location → Optional Image → Duplicate Check → Confirmation → Submit

### Possible Duplicate
Show:
- possible duplicate label;
- existing complaint title;
- location;
- status;
- option to open/follow existing complaint;
- explicit Submit Anyway action.

### Complaint Details
- complaint ID
- title
- description
- location
- status
- timeline
- notifications/updates

## Admin dashboard

### Main dashboard
- complaint counts
- queue
- filters
- recent activity

### Complaint detail
- complaint information
- location
- priority
- department
- staff assignment
- lifecycle/status history

The exact visual design can evolve during implementation, but these flows are the Week 1 product boundaries.
